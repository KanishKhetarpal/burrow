# 05 — PWA UI Spec

Mobile-first for iPhone (390–430 pt wide), with a responsive **wide layout for the laptop** (≥ 900 px: left sidebar nav instead of bottom tabs, terminal and file list side by side, keyboard shortcuts: `N` new chat, `/` search files). iPhone: Safari → Share → Add to Home Screen. Laptop: Chrome/Edge *Install app* or Safari *Add to Dock*. Standalone display, respects safe areas (`env(safe-area-inset-*)`), light/dark from system. Tap targets ≥ 44 pt. One-hand use: primary actions in the bottom half.

Visual direction: calm, utilitarian, dark-first. One accent color. System font stack (`-apple-system`). No external fonts or CDNs.

## Navigation

Bottom tab bar: **Home · Sessions · Files · More**. Persistent status pill at top: `● Online` / `○ Offline` / `◐ Waking`.

## Screens

### 1. Unlock
- Shown when paired but no valid session.
- Large "Unlock with Face ID" button → passkey login. Auto-triggers once on open.
- After 5 failures: "Locked for 15 minutes".
- If lockdown: "Burrow is locked down. Unlock it at your PC with `burrow unlock`." No other UI.

### 2. Pair (first run, `/pair`)
1. "Enter the 6-digit code shown on your PC."
2. "Create a passkey" → Face ID.
3. Optional: "Paste your Termius public key" (textarea + "Skip").
4. "Add Burrow to your Home Screen" instructions with an illustration (if not yet standalone).
5. Done → Home.

### 3. Home
- **Status card:** hostname (random name shown as "Your PC"), uptime, CPU/RAM bars, keep-awake indicator, running sessions count.
- **Offline state** (served from the service worker cache): big **Wake PC** button and last-seen time.
  - Tap → opens the **"PC On"** shortcut (plug on). On return, a stepper `Power on → Booting → Online` with elapsed time. On Online → auto reload → Unlock.
  - After 90 s without Online: amber card "Still off? The plug may have been left on." → **Power-cycle** → warning sheet "Only do this if the PC is fully shut down. It cuts power for 15 s." → confirm → opens **"PC Power Cycle"** shortcut.
  - **On the laptop** (detected by device kind from `/api/auth/me`, cached): Wake shows "Wake from your iPhone: run PC On, or say 'Hey Siri, PC On'" and then polls for Online the same way. No shortcut links on the laptop.
  - If the shortcut doesn't exist, show setup help: "Create shortcuts named PC On / PC Off / PC Power Cycle in the Shortcuts app" with steps.
- **Primary actions (Online):**
  - **New Claude chat** (largest button)
  - **Open terminal** → `ssh://<user>@<pc-magicdns>` (opens Termius)
  - **Files**
- **Recent projects** row: one-tap "New chat in <project>" chips (top 4).

### 4. New chat sheet (bottom sheet)
- Project picker (search + recent first).
- Name (prefilled `<project>-<HHmm>`).
- Mode: **Chat** (default) / **Project server** (with helper text: "start more chats from inside the Claude app").
- Permission mode: Default / Accept edits / Plan.
- Worktree toggle (server mode, git repos only).
- **Start** → progress: Starting → Connecting Remote Control → Ready.
- Ready state: **Open in Claude** (primary, universal link `remoteUrl`) and **View terminal**. If `needs_input`, show the prompt text with quick-reply buttons (e.g. "Trust folder", "Enable Remote Control", "Yes", "No").
- Fallback after 30 s with no URL: "Open the Claude app → Code tab. Your session is listed as <name>." + **Open Claude app** (`https://claude.ai/code`).

### 5. Sessions
- List cards: name, project, status dot (green ready/running, amber needs_input, grey stopped, red failed), started relative time.
- Swipe or ⋯ actions: Open in Claude, View terminal, Stop, Resume, Delete.
- Top-right: **Stop all** (confirm).

### 6. Terminal view
- xterm.js full-screen, fit addon, font size controls (A− / A+).
- Read-only by default with a lock toggle ("Tap to type").
- Mobile key bar above the keyboard: `Esc` `Tab` `Ctrl-C` `↑` `↓` `←` `→` `y` `n` `Enter` `/`.
- Status banner for `needs_input` with quick replies.
- Reconnects automatically with backoff; shows "Reconnecting…".

### 7. Files
- Root picker → breadcrumb → list (name, size, modified).
- Tap file: preview (image/PDF/text) with **Download/Share** (uses iOS share sheet via `navigator.share` with File when supported).
- **Upload** button: iOS picker (Photos, Camera, Files), multiple files, progress per file.
- Long-press: Rename, Delete (step-up), New folder.
- Footer tip: "Prefer native? Files app → Connect to Server → smb://<pc-name>".

### 8. More
- **Power:** Lock, Restart (step-up), **Shut down** (step-up), Sleep (tagged "can't be woken from the phone"). Keep awake: toggle + duration (30 m, 1 h, 2 h, 4 h, until off). Auto-shutdown when idle: Off / 30 m / 1 h / 2 h.
  - After **Shut down**: full-screen "Shutting down…" that watches `/healthz`. Once it has failed continuously for 30 s: "PC is off. Cut plug power?" → **Turn plug off** (opens "PC Off" shortcut) or **Leave on**. This prompt appears only after a Burrow-initiated shutdown, never after an unexplained disconnect.
- **Security:** paired devices (iPhone, laptop; revoke with step-up), **Add SSH key** (step-up), audit log (filter by action and device), **Lockdown** (red, step-up, double confirm).
- **Projects:** list, add (step-up).
- **About:** versions, agent FQDN, wake method and shortcut names.

## States and errors
- Network timeout to agent (4 s) → Offline UI (never a blank screen).
- `stepup_required` → Face ID sheet, then retry the action automatically.
- `max_sessions` → "You have N sessions running. Stop one first."
- Toasts for success; inline errors with retry.

## Accessibility
- Dynamic Type friendly (rem units), VoiceOver labels on icon buttons, contrast ≥ 4.5:1, `prefers-reduced-motion` respected.

## PWA details
- `manifest.webmanifest`: name "Burrow", short_name "Burrow", display standalone, theme/background colors, icons 180/192/512 (simple original glyph, no third-party marks).
- `apple-touch-icon`, `apple-mobile-web-app-capable`, `apple-mobile-web-app-status-bar-style=black-translucent`.
- Service worker: precache shell on install; navigation = network-first (4 s) then cache; `/api/wake-config` = stale-while-revalidate; never cache other `/api/*` responses.
